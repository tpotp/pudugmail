Política de Privacidad

Última actualización: 18 de agosto de 2026

1. Introducción

Bienvenido a Pudú Mail - Attachment Explorer (accesible en https://pudugmail.vercel.app), una herramienta web diseñada para ayudarte a explorar, ordenar y gestionar los archivos adjuntos de tu cuenta de Gmail para liberar espacio de almacenamiento.

Nos tomamos tu privacidad con la máxima seriedad. Esta aplicación ha sido construida bajo la filosofía de Procesamiento 100% en el Dispositivo (Client-Side). Tus correos electrónicos, adjuntos y datos personales nunca se envían a ningún servidor externo.

2. Declaración de Cumplimiento con Google API Services (Limited Use Disclosure)

Google API Services User Data Policy Compliance:
Pudú Mail - Attachment Explorer's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Pudú Mail - Attachment Explorer cumple estrictamente con los requisitos de Uso Limitado de Google para permisos restringidos de la API de Gmail.

3. Permisos de Google Solicitados y su Uso

La aplicación solicita acceso a los siguientes permisos (OAuth Scopes) de Google:

  • https://www.googleapis.com/auth/gmail.readonly: Utilizado exclusivamente en tu navegador para leer los encabezados y adjuntos de tus correos y permitirte ordenarlos por tamaño (fotos, videos, documentos).
  • https://www.googleapis.com/auth/gmail.modify: Utilizado únicamente cuando haces clic explícito en "Borrar de Gmail" o "Mover al Dispositivo", para trasladar a la papelera de Gmail el correo específico que autorizaste eliminar.

4. Almacenamiento y Seguridad de los Datos

  • Sin Servidores Propios: La aplicación corre enteramente en tu navegador web. No poseemos servidores de base de datos ni registramos tus correos.
  • Tokens de Autenticación: Tu token de acceso de Google se almacena únicamente en la memoria volátil de tu sesión de navegación y expira automáticamente.
  • Almacenamiento Local (IndexedDB): Para permitir una navegación rápida y vistas previas instantáneas, la aplicación almacena localmente en la memoria de tu propio navegador las miniaturas y la lista de adjuntos escaneados. Puedes borrar estos datos en cualquier momento limpiando el historial o la caché de tu navegador.

5. Política de Publicidad y No Comercialización

  • Cero Venta de Datos: Nunca vendemos, alquilamos ni transferimos tus datos de Gmail a terceros.
  • No Uso para Publicidad Personalizada: Tus datos de Gmail, correos y adjuntos JAMÁS se utilizan para segmentación publicitaria ni para alimentar modelos de inteligencia artificial o anuncios dirigidos.
  • Anuncios Generales: En caso de mostrar publicidad general en el sitio web, esta se basará únicamente en el contexto general de la página web y nunca tendrá acceso a tus correos o archivos personales.

6. Control del Usuario y Revocación

Puedes revocar el acceso de Pudú Mail a tu cuenta de Google en cualquier momento desde la página de seguridad de tu cuenta de Google: https://myaccount.google.com/permissions.
